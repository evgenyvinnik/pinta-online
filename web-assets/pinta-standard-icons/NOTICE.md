## Adwaita symbolic icons

These SVGs come from Adwaita Icon Theme 50.0, the GTK icon theme used by the
reproducible native Pinta screenshot environment in `tests/visual/native/`.
They are included so the web implementation can render the exact standard icon
names referenced by `original/Pinta.Resources/Icons.cs`.
