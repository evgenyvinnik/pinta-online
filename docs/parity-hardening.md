# Functional parity hardening

Visual reference screenshots define Pinta Online's layout contract, but behavioral parity is verified separately. This matrix records the browser implementation used at native or operating-system boundaries and the deterministic test that protects it.

| Area | Pinta Online behavior | Fallback or boundary | Verification |
| --- | --- | --- | --- |
| Unsaved documents | Save opens Save As; closing an unsaved multilayer document proceeds through Save As and the flat-format confirmation before closing | A canceled picker leaves the document open and dirty | `routes an unsaved close through Save As and flatten confirmation before closing` |
| Clipboard | Copy, Copy Merged, and Cut publish `image/png`; Paste reads image clipboard items; oversized images retain Expand / Preserve / Cancel | Browsers without clipboard-read permission retain the in-app image clipboard; an empty or text-only clipboard opens Pinta's explanatory alert | `imports and exports PNG images through the operating-system clipboard bridge`; `explains an empty clipboard instead of silently ignoring paste` |
| File integration | Files opened by the File System Access picker or installed-PWA launch queue retain their `FileSystemFileHandle`; Save writes back to that exact file; picker cancellation is a focus-preserving no-op; rejected writes stay dirty and open the diagnostic error shell | Browser file inputs and browsers without the File System Access API use download-based Save / Save As | `keeps native file handles attached to their tabs and saves back in place`; `reports native file-handle save failures with diagnostics and preserves the dirty document`; `treats browser file-picker cancellation as a no-op and restores command focus` |
| Browser image encoders | PNG, JPEG, and WebP exports verify the returned Blob MIME before naming or writing it | A browser that silently substitutes PNG for an unavailable encoder receives Pinta's unsupported-format error; mislabeled bytes are never downloaded | `rejects a browser encoder fallback instead of saving PNG bytes with a WebP name` |
| Installed-app launch | Launch files wait until IndexedDB restoration completes, open independently in order, and retain each valid source handle | A corrupt or unsupported launch file is reported without preventing later files from opening | `opens every valid installed-PWA launch file after workspace restoration` |
| Undo history storage | Every named history entry, selection mask, floating selection, and layer state survives reload; adjacent entries structurally share byte-identical layer pixel buffers in memory, and restored histories are deduplicated again after decoding | Persistence remains complete snapshots so a browser/database interruption cannot break a diff chain; recent-document integration remains browser/OS-owned | `restores the complete persisted undo and redo timeline instead of a synthetic session entry` |
| Portable Pixmap | P3 text and P6 binary RGB decode, including comments, 8/16-bit samples, scaling, and truncation/range validation | Export stays P3 for broad compatibility and inspectability | `npm run verify:image-codecs` |
| Targa | Raw or RLE true-color, grayscale, grayscale-alpha, palette indices, 15/16/24/32-bit color, and all origin flags decode | Export stays deterministic uncompressed 32-bit BGRA | `npm run verify:image-codecs` |
| Bitmap | 1/4/8-bit palettes, RLE4/RLE8 streams, 16/24/32-bit pixels, top-down rasters, bitfields, and alpha bitfields decode; export is deterministic 32-bit BGRA | Unsupported or malformed compression fails with an explanatory error | `npm run verify:image-codecs`; `opens and saves deterministic alpha-aware BMP images` |
| TIFF | The first displayable baseline or compressed IFD decodes; export writes interoperable uncompressed RGBA | Multi-page TIFF opens as one Pinta document, matching desktop's single-image document model | `npm run verify:image-codecs`; `opens and saves TIFF through the deterministic codec bridge` |
| OpenRaster | Layers, order, offsets, names, visibility, opacity, blend modes, merged image, and thumbnail round-trip | Invalid/missing layer entries are skipped and reported without discarding valid layers | `npm run verify:openraster`; `places OpenRaster layers at their declared offsets and skips missing layers` |
| JPEG | Flat export uses a separate 1–100 quality confirmation with the native default, after layer-flatten confirmation when needed | The final destination picker remains browser/OS-owned | `uses Pinta's separate JPEG quality step and a JPEG-only platform picker` |
| Text editing | Multiline selection/caret behavior comes from a focused textarea; browser-local undo, clipboard, IME composition, tabs, bidi direction, formatting shortcuts, and bracket size shortcuts are preserved | Each layer retains one independent re-editable text engine; conflicting pixel edits finalize only that layer's record | `supports native text sizing, tab input, bidirectional content, and IME-safe commits`; `keeps one native re-editable text engine per layer across switches and reloads` |
| Selection options | Selection Mode preserves Pinta's platform-specific command labels in a native-style text chooser; Autoscroll uses the original Zoom Blur/Unfocus icons; all flyouts place the selected check at the trailing edge and support arrow/Home/End navigation, Escape focus restoration, and viewport collision handling | The underlying selection marquee is a canvas animation rather than a GTK overlay | `matches native selection mode labels and operates icon flyouts from the keyboard`; `uses native text choosers for selection, brush, eraser, and text join options`; `native autoscroll chooser reuses the Pinta effect icons` |
| Tool option choosers | Paintbrush Type, Eraser Type, and Text Join use the native ordered text-combo model; Color Picker sampling/source/after-select use visible labels and the original Pinta/GTK icons | Popovers are accessible browser controls styled to the native contract rather than GTK widgets | `uses native text choosers for selection, brush, eraser, and text join options`; `uses native icon-and-label choosers for every Color Picker option`; pinned `tool-*-flyout` screenshots |
| Bundled add-in dialogs | Ars Kali controls preserve source declaration order/ranges/defaults; Chromatic Aberration exposes three image-backed pixel-coordinate `PointI` controls; Hexagon Pixelate uses the shared point picker and nested full color dialog; Block Brush is an optional Paintbrush type | Native Mono.Addins assemblies cannot execute in a browser, so reviewed ports are bundled, typed, and opt-in | `maps Chromatic Aberration PointI controls to native image coordinates`; `manages bundled add-ins, exposes their tools and effects, and persists the choice`; pinned add-in dialog/output screenshots |
| Color picking | Single-color mode includes persistent Recently Used and current Palette rows; dual primary/secondary mode hides those rows, updates live, swaps both colors, and restores the original pair on Cancel; both modes share the HSV/RGB/alpha core and native collapse control | Browser canvas/CSS render the picker surface instead of Cairo/GTK | `offers a full Pinta color picker and discoverable palette editing`; `dialog-edit-palette-color`; `dialog-primary-secondary-color` |
| Layer dialogs | Layer Properties previews name, visibility, opacity, and blend mode without history, rolling back on Cancel; Rotate / Zoom uses Pinta's right-zero/counter-clockwise angle dial, image-backed pixel-coordinate point picker, normalized internal zoom/pan, live composite preview, and one final history entry | Pixel coordinates are translated to normalized values at the web rendering boundary; odd-sized images retain an exact zero pan until the user moves the integer point control; preview pixels are composited into the web preview canvas rather than a temporary Cairo layer transform | `edits layer properties and applies a non-dialog adjustment`; `previews Rotate / Zoom Layer live and clears or commits the transform exactly once`; `keeps an odd-sized layer centered when Rotate / Zoom first opens`; `supports direct pointer and keyboard input on native point and angle pickers` |
| Application errors | Blocking file, save, palette, layer, effect, screenshot, workspace, and uncaught asynchronous failures use Pinta's heading/body shell, expandable diagnostics, default OK response, and `Report Bug...` action | Bug reports target the Pinta Online repository because the failure occurred in the web port | `opens every valid installed-PWA launch file after workspace restoration`; `dialog-error-report`; `dialog-error-report-details` |
| About window | The compact 360 × 624 shell keeps Details, Credits, and Legal as navigable pages; support and issue rows remain direct links; web-port credit links Evgeny Vinnik to the Pinta Online repository | Details identify both the online build and upstream Pinta version; locale translator credits come from Pinta's catalogs | `routes source and bug reports to the Pinta Online repository`; `dialog-about`; `dialog-about-details`; `dialog-about-credits`; `dialog-about-legal` |
| Effect dialogs | Reflective dialogs use scale/spin/reset, native right-zero/counter-clockwise angle dials, image-backed pixel-coordinate Point/CenterOffset pickers, seed/Reseed, enum, and nested color controls with live preview, native ranges/defaults/raw enum captions, upstream hints, scrollable content, and pinned Cancel/OK actions | Center-offset pixel coordinates are converted to normalized processor values; see Effect rendering below for the worker progress boundary | `supports direct pointer and keyboard input on native point and angle pickers`; `preserves native effect hints and raw dithering palette names`; `keeps tall native effect dialogs usable in a narrow viewport` |
| Effect rendering | Stale live previews abort instead of queuing; confirmed effects use an isolated worker and expose a native-style cancellable, determinate progress dialog fed by processor row/pixel/work-unit checkpoints | Native Pinta reports renderer tiles; the web worker reports equivalent processor completion fractions because its algorithms are not tile-scheduled | `cancels native effect rendering without changing pixels or history` |
| Zoom model | Zoom In / Zoom Out step `ViewActions`' 23-entry zoom collection (3600%–5%); the status bar carries Pinta's editable combo with those presets plus `Window`; a typed percentage snaps to the next preset when stepped; every newly opened document is fitted the way `MainWindow` fits a canvas on first show | `Window` stays armed across viewport resizes, which a fixed-size GTK window never needed; documents restored from IndexedDB keep their saved zoom instead of being re-fitted | `steps the native zoom collection and renders zoomed-in pixels without smoothing`; `keeps Window zoom fitted to the viewport until an explicit level replaces it` |
| Canvas resampling | Above 100% the canvas renders nearest-neighbour and below it renders smoothed, matching `CanvasRenderer.cs`'s `scale_ratio` rule | Cairo filters become the CSS `image-rendering` property on the composited display canvas | `steps the native zoom collection and renders zoomed-in pixels without smoothing` |
| Toolbox layout | The tool grid reflows with the available height like `ToolBoxWidget`'s vertical `Gtk.FlowBox`: one column when tall, up to three when short, never clipping a tool | Overflow at very short heights scrolls with a visible thin scrollbar rather than GTK overlay scrolling | `reflows the toolbox with the window instead of clipping tools` |
| Dock panels | The canvas/dock splitter, the Layers/History splitter, and each pad's minimize control persist, mirroring `dock-right-splitpos`, `dock-{pad}-splitpos`, and `dock-{pad}-minimized` | A minimized pad collapses to its own header instead of moving into a GTK dock bar | `resizes, minimizes, and restores the docked tool windows` |
| Status bar | The second readout reports the selection bounds and falls back to the canvas size, and the recently-used block shows `MAX_RECENT_COLORS` swatches over two rows with primary/secondary click behavior | Touch has no right button, so a long press stands in for the secondary-colour click | `reports the selection size and recently used colors in the status bar` |
| Tool settings scope | Brush width, antialiasing, alpha blending, fill style, and dash pattern are stored per tool, matching `Pinta.Tools/SettingNames.cs` | A previously persisted global value seeds every tool, so upgrading keeps existing settings | `scopes brush width, antialiasing, and shape style to each tool` |
| Icon references | Every icon name in the source resolves to a real Pinta or GTK icon file | The SPA fallback answers an unknown `/actions/*.svg` with `index.html` rather than a 404, so a typo renders blank instead of failing | `npm run verify:icons`; `loads every rendered icon from Pinta or its native GTK icon contract` |
| Effect algorithms | All 46 built-in adjustments/effects have been read against native. Byte fixtures cover fixed-point Fragment/Motion/Radial/Zoom sampling; RGSS and effect-specific Bulge/Dents/Polar/Tile/Twist grids; native seeded Cells, Voronoi, and Frosted Glass; Mandelbrot; translucent premultiplied gradients; Pixelate and Outline Object; Align Object centering; Ink Sketch and Soften Portrait composition; exact preset/current/recent dithering palettes; and every RGB-cube dithering value. Pencil Sketch deliberately reproduces native overwriting its own Color Range pass | Unary ops run on the canvas' straight-alpha buffers rather than Cairo's premultiplied surfaces, which only differs on translucent pixels and avoids a browser-only quantization round trip | `npm run verify:effects` |
| Gaussian blur family | The blur is the Paint.NET tent kernel with alpha-weighted accumulation and out-of-surface samples excluded from the weight sum, byte-identical to `GaussianBlurEffect.Render` | Canvas buffers are already straight-alpha, so the native premultiply round trip has no counterpart | `npm run verify:effects` |
| Phones and touch | Below 640px the menu bar and secondary toolbar commands collapse into the Main Menu, the toolbox becomes a horizontal strip, and the docked pads start closed, leaving the canvas the rest of the screen | Pinta has no phone mode; every hidden command stays reachable through the Main Menu, and `pointer: coarse` enlarges the controls people tap | Manual: draw, long-press a swatch, and pinch-zoom at 390x844 |
| Printing | Pinta owns a frozen composite preview, portrait/landscape, fit/actual/custom scale, margins, centering, and the isolated print-only surface; `afterprint` disposes it | Paper, printer, PDF destination, final Print/Cancel, and driver options remain browser/OS-owned | `applies page setup to the isolated browser print surface` |

## Deliberate platform boundaries

Pinta Online does not imitate a filesystem browser, printer-driver window, screen-capture permission prompt, or browser permission prompt. Those surfaces must remain owned by the browser or operating system for security. The application preserves Pinta's command flow and state on both sides of each boundary, including cancellation and failure paths.

Native Mono.Addins assemblies also cannot execute in the browser. Reviewed add-ins are ported into the typed tool/effect registry and remain opt-in.

Run the full behavioral contract with `npm run test:e2e`, codec fixtures with `npm run verify:image-codecs`, and the pinned visual contract with `npm run test:visual`.
