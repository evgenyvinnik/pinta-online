## Independent compatible implementations

The following features were implemented independently for the browser from public feature descriptions and observable behavior. Their upstream source code is not incorporated into Pinta Online:

- [Ars Kali: Glitches](https://github.com/hyenaheartbeats/Ars-Kali--Glitches), by Kali Rosenkreuz: Chromatic Aberration, Scanlines, Colored Artifacts, Pixel Drag, Row Slice, and Adjustment Noise.
- [Colored Grayscale](https://github.com/Intedai/ColoredGrayscaleAddin), by Intedai: grayscale-on-colored-paper behavior using the active primary color.

The upstream repositories retain their own licenses. No source files from those repositories are distributed as part of these independent implementations; consult each upstream project for its licensing terms.
